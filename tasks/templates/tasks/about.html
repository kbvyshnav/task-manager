About

A task management web application built with Python and Django 5. Developed as a hands-on learning project to understand the Django framework end-to-end — from models and views to forms, the ORM, and the admin interface.

Features

  • Create, edit, and delete tasks
  • Mark tasks as done / pending with one click
  • Set priority levels: High, Medium, Low
  • Assign tasks to colour-coded categories
  • Due dates to track deadlines
  • Filter tasks by status, priority, or category
  • Dashboard with live stats (total, pending, done)
  • Django Admin with batch actions and search

Tech Stack

  • Backend: Python 3, Django 5.2
  • Database: SQLite (development)
  • Templates: Django Template Language (DTL)
  • Styling: Plain CSS — no external frameworks
